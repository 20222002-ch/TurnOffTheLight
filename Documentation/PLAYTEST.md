검증 중 **완료된 저장을 재실행하면 다음 건물로 진행할 수 없는 문제**를 발견했습니다. 초기 `wasComplete`를 false로 설정하여 로드된 완료 상태에서도 완료 화면이 표시되도록 수정했고, 위의 완료 저장·버튼 클릭·다음 건물 회귀 확인을 완료했습니다.

연쇄·수직 전파 검사는 최대 강화 상태를 주입한 검증용 상태로 수행했습니다. 순차 암전과 층 전체 완료가 실제 프레임에 걸쳐 발생하는지 확인한 결과이며, 일반 플레이의 성장 시간이나 밸런스를 측정한 결과가 아닙니다. 일시 정지 시 남은 전파는 대기 상태로 유지되며, 전파의 유한 종료는 위 모델 검사에서도 확인했습니다.

빌드와 배포 실행 검증은 이번 작업 범위에서 제외합니다. 카메라 활성 층 수와 고정 풀 확인은 렌더링 범위를 관측한 결과이며, 평균 FPS나 최소 사양 성능 측정은 아닙니다. 실제 실행 결과를 모델 통과 수치와 합쳐 표현하지 않습니다.

Edit Mode에서도 메인 씬은 `Assets/LightsOut/Scenes/LightsOut.unity`이며, 씬의 플레이어 프리팹 참조와 실제 프리팹 자산 모두 `Assets/LightsOut/Prefabs/Player.prefab`으로 확인했습니다. 검증 전의 PlayerPrefs와 저장 파일을 원상 복원한 결과도 일치했습니다.

Git 작업 상태: 로컬 `.git`과 remote가 없어 `git status`는 실패했으며 저장소 초기화·원격 작업은 수행하지 않았습니다. 프로젝트 루트 `.gitignore`에 Unity Library·Temp·Logs·Build 등 생성물 제외 규칙을 추가했습니다.

포인터 입력과 Play Mode 확인은 실제 실행 검증입니다. 순수 모델의 전체 성장 검사는 모든 구역에 대한 사람의 수동 플레이를 대신하지 않습니다. 프레임 카운터 확인은 실행이 진행 중인지 확인한 것이며, 평균 FPS나 최소 사양 성능을 측정한 결과는 아닙니다.

## 점검 중 반영한 사항

- 자동화 설명을 실제 처리 대상인 일반·고장·자동 점등 전등에 맞춤
- 저주 조건 안내를 다른 전등 3개 소등 조건에 맞추고 봉인 해제 상태 구분
- 전등 위에 마우스를 올리는 동안 처리 안내가 유지되도록 수정
- 일시 정지 중 광역·전체 소등이 발동하지 않도록 입력 조건 적용
- 후반 전등 격자의 클릭 영역과 표시 밀도를 점검하고 화면 확인
- 초기화는 새 게임 확인 화면을 거치도록 구성
