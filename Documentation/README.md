# 불 끄고 퇴근해! — Lights Out!

가로로 긴 대형마트의 불을 끄며 밀린 월세를 갚는 Unity 2D 게임입니다. DAY가 진행될수록 건물은 가로로 좁아지고 세로로 높아집니다. **DAY마다 최대 5번 근무하고, 월세를 갚으면 잔액과 일반 스킬을 다음 DAY로 이월합니다.** 게임오버 후에도 관리인 포인트와 액세서리는 남습니다.

- 상태: 메인 개발 후보의 이동·소등·월세·퇴근 룰렛 MVP
- 프로젝트: `D:\unity_projects\TurnOffTheLight`
- 환경: Unity **6000.3.8f1**, URP 2D, uGUI, Input System
- 기준일: **2026-10-14, 한국 시간**
- 이번 범위: 기존 프로젝트 구현·문서·Editor 검증. 실행 파일 빌드, Notion 작업, GitHub 푸시는 수행하지 않습니다.

## 실행과 조작

기존 `Assets/LightsOut/Scenes/LightsOut.unity` 씬에서 Play를 누릅니다. 근무 준비 화면에서 액세서리를 선택하고 근무를 시작합니다. **기회는 시작 버튼을 누를 때 1회 차감**되며, 완료·시간 만료 때 다시 차감하지 않습니다.

| 입력 / 화면 | 동작 |
| --- | --- |
| WASD / 방향키 | 자유 이동. 대각선 속도 보정, 중력·낙하·벽 충돌 없음 |
| 켜진 방 안에 머무르기 | 기본 1초 작업 후 소등. 마우스로 방을 클릭하지 않음 |
| Space | 대시 스킬 해금 후 마지막 이동 방향으로 대시 |
| R | 후반 `수직 돌파` 해금 후 위로 순간 상승 |
| T / 정산의 강화 버튼 | 스킬 트리. 열려 있는 동안 근무·이동 일시 정지 |
| ESC | 일시 정지 / 메뉴 복귀. 진행 중인 룰렛은 닫을 수 없음 |
| 근무 준비 화면 | 관리인 포인트로 액세서리 획득·강화·최대 3개 장착 |
| 퇴근 정산 | 그대로 받기, 별도 룰렛 창, 월세 납부, 일반 강화, 다음 근무 |

근무 화면은 인게임을 화면 전체로 보여줍니다. 이전의 상시 장부·업그레이드 대시보드·줌 버튼 등은 숨깁니다. 작업 원형 게이지, 소등 보상·콤보 피드백과 마지막 5초 카운트다운은 진행에 필요한 표시입니다. **근무가 끝나면 기존 메인 정산 화면으로 돌아갑니다.**

## DAY와 건물 성장

| DAY | 가로 열 × 층 | 방 수 | 기본 제한 시간 |
| ---: | ---: | ---: | ---: |
| 1 | 20 × 2 | 40 | 80초 |
| 5 | 14 × 5 | 70 | 90초 |
| 10 | 9 × 12 | 108 | 100초 |
| 20 | 6 × 28 | 168 | 110초 |
| 40 | 4 × 60 | 240 | 120초 |

중간 DAY는 키프레임 사이를 보간합니다. DAY 40 이후 기본값은 4열을 유지하고 하루마다 2층·1초 증가하며, 제한 시간은 150초, 논리 층수는 4,096층까지입니다. 기본 방 폭은 2.4로 DAY 1 전체 폭은 48입니다. 초반 카메라는 가로 이동에 맞추고, 후반에는 세로 추적 중심으로 전환합니다. 가구·NPC·복잡한 인테리어는 추가하지 않습니다.

DAY 1의 **기본 전체 소등 수입은 202.5, 월세는 527**입니다. 실제 수입에는 콤보·이동 보너스·배지·룰렛이 적용되므로 기본 수입보다 커질 수 있습니다. 월세는 키프레임별 기본 전체 소등 수입을 연속 보간한 별도 기준액으로 산정합니다. 열·층 반올림 때문에 DAY가 올라도 월세가 내려가는 문제를 방지합니다. 신규 DAY 2의 월세는 634이며, 기존 진행의 옛 DAY 2 월세 273은 저장된 계획에 따라 유지합니다. 수치는 현재 MVP 기본값이며 장기 출시 밸런스는 검토 중입니다.

## 작업·콤보·일반 스킬

방에 닿으면 작업을 시작하고, 기본 1초가 누적되면 불이 꺼집니다. 방을 떠나도 기본 **1.5초** 동안 진행도를 보존하여 다시 들어오면 이어서 작업합니다. 작업 장갑은 보존 시간을 늘립니다. 소등 속도 강화는 이동속도와 별개이며 최종 레벨에서는 이동 경로의 방을 접촉 즉시 소등합니다.

불이 새로 꺼질 때만 콤보를 1 증가시키고 유지 시간을 **4초**로 갱신합니다. 직접 작업, 상층 연동, 연쇄와 자동 소등도 새 방을 처리하면 집계합니다. 같은 방을 두 번 처리하여 콤보나 보상을 얻을 수 없습니다.

| 현재 콤보 | 해당 소등의 수익 배율 |
| ---: | ---: |
| 1–4 | ×1 |
| 5–9 | ×1.2 |
| 10–19 | ×1.5 |
| 20 이상 | ×2 |

콤보 배율은 각 소등 시점에 적용하며 이전 보상을 다시 계산하지 않습니다. 4초 동안 새 소등이 없으면 현재 콤보는 초기화되고 이번 근무의 최고 콤보는 남습니다.

일반 스킬은 총 **25개**, 4계열입니다. 보유금으로 구매하며 선행 조건과 DAY 조건을 모두 표시합니다.

| 계열 | 스킬 |
| --- | --- |
| 이동 강화 · 6개 | 이동속도, 소등 범위, 대시, 대시 거리, 이동 보너스 수익, **소등 속도 강화** |
| 연쇄 강화 · 5개 | 연쇄 소등, 연쇄 확장, 연쇄 가속, 과부하, 블랙아웃 |
| 수직 돌파 · 9개 | 수직 소등, 층 전체 정전, 수직 관통, 상승 가속, 초고속 돌파, **건물 가로 축소, 수직 돌파, 상층 연동 소등, 층 완료 정전** |
| 자동화 · 5개 | 자동 스위치, 자동 소등 속도, 자동 층 정전, 자동 연쇄, 완전 자동화 |

초기에는 이동속도·소등 속도·상층 연동을 사용할 수 있습니다. 대시 DAY 5, 연쇄·층 전체 정전·가로 축소 DAY 10, 자동 스위치·수직 관통 DAY 15, 액티브 수직 돌파 DAY 20 등이 기본 해금 시점입니다. 가로 축소는 레벨당 7%, 최대 35%이며 방 ID·전등 수·월세는 바꾸지 않습니다. 액티브 수직 돌파는 수직 관통 Lv.3을 요구하고 8/12/16층을 약 0.28초 동안 상승하며 재사용 시간은 14/12/10초입니다.

상층 연동은 직접 소등한 위치 위쪽 1/2/3층을 즉시 함께 처리하고 자기 자신을 재발동하지 않습니다. 층 완료 정전은 인접한 위아래 층 1/2/3개 방을 예약 소등하며 동일 전파의 층 완료 확산은 최대 2회입니다. 모든 전파는 방문 기록과 프레임 처리량 제한을 사용합니다.

## 정산·월세·룰렛

**근무 → 소등·미정산 수입 → 완료 또는 시간 만료 → 그대로 받기 / 룰렛 → 월세 납부 / 강화 / 다음 근무**

이번 근무 수입과 이전에 정산한 보유금을 분리합니다. 이번 수입은 정산 전 구매에 사용할 수 없습니다. 월세를 낼 때는 보유금에서 월세를 차감하고 잔액·일반 스킬을 이월하며, 다음 DAY 근무 준비 화면과 새 5회 기회로 이동합니다. 같은 DAY의 다음 근무는 같은 건물·시간으로 바로 시작하며 액세서리를 교체할 수 없습니다.

| 선택 | 이번 근무 수입 처리 | 기본 확률 |
| --- | --- | ---: |
| 그대로 받기 | ×1 지급 | 확정 |
| 룰렛 NOTHING | 이번 수입 ×0 | 60% |
| 룰렛 ×2 | 이번 수입 ×2 | 37% |
| 룰렛 ×10 | 이번 수입 ×10 | 3% |

퇴근 정산이 메인 화면이고 룰렛 휠은 별도 팝업에 있습니다. 팝업을 열기만 하면 베팅하지 않습니다. 돌리기 버튼을 누르면 결과와 지급을 저장한 뒤 약 6.4초 동안 티켓 이동·가속·고속 회전·감속·결과 공개를 연출합니다. 팝업을 닫기 전에는 메인 잔고 표시를 고정합니다. 회전 중 ESC·T·월세·구매·다음 근무·재추첨은 차단합니다.

21개 저장 슬롯은 유지합니다: 0–9는 ×2, 10–19는 NOTHING, 20은 ×10입니다. **21칸이 동일 확률인 구조는 아닙니다.** 표시에서는 ×2와 NOTHING을 섞고, 칸의 각도·면적과 실제 추첨 확률을 맞춥니다. 기존 보유금은 걸지 않으며 한 근무에 한 번만 선택합니다.

다섯 번째 근무 정산 후 월세가 부족하면 게임오버입니다. 재시작하면 DAY·보유금·일반 스킬은 초기화하지만 관리인 포인트와 액세서리는 보존합니다. 마지막 정산 후 돈이 충분하면 정상 납부할 수 있고, 월세 예비금을 부족하게 만드는 일반 강화 구매는 거절합니다.

## 관리인 포인트와 액세서리

이전에 완납한 최고 DAY보다 높은 DAY의 월세를 처음 낼 때 **1 + min(3, 남은 기회)** 포인트를 받습니다. 동일하거나 낮은 DAY를 반복하여 포인트를 얻을 수 없습니다. 액세서리는 최대 3개를 장착하며 새 DAY 또는 게임오버 후 재시작의 근무 준비 화면에서만 변경합니다. 효과는 근무 시작 때 복사하여 근무 중에는 바뀌지 않습니다.

| 액세서리 | 기본 효과 / 강화 |
| --- | --- |
| 작업 장갑 | 작업 진행도 보존 +0.5초/레벨 |
| 야간 운동화 | 현재 콤보별 이동속도 증가, 최대 20콤보까지 반영 |
| 관리인 열쇠 | 시작 시 3개 방 자동 소등, 추가 레벨마다 +2개 |
| 전기 반지 | 직접 소등 성공 시 주변 소등 확률 +10%/레벨 |
| 성과 배지 | 퇴근 정산 전 최고 콤보 × 0.25/레벨을 한 번 추가 |

기본 강화 상한은 Lv.5, 첫 가격은 순서대로 3/4/5/5/6 포인트, 이후 가격 성장률은 1.8입니다. 미장착 액세서리는 효과를 주지 않습니다. 배지 보너스는 이번 근무 수입에 포함되어 일반 정산·룰렛 대상이 됩니다.

## 리소스·설정·저장

`Assets/LightsOut/Resources/LightsOutBalanceSettings.asset`은 Inspector에서 DAY 키프레임, 제한 시간, 방 폭, 소등 시간, 스킬 해금 DAY, 콤보, 룰렛 확률, 액세서리 가격을 조절하는 설정 자산입니다. 현재 DAY 계획은 저장하여 설정 변경·재접속이 진행 중인 채무와 건물을 바꾸지 않습니다.

논리 상태는 최대 4,096층·20열로 제한하며 표시에는 **48개 층 × 20개 방 슬롯**만 사용하고 가로 화면 밖의 방은 숨깁니다. 소등 피드백은 보상 팝업 24개·스파크 48개, 상승 연출은 SpriteRenderer 12개, 작업 원형 게이지는 32개 구간을 사용합니다. 이는 자원 수를 제한한 구현이며 저사양 성능 측정을 완료했다는 의미는 아닙니다. 기존 도형·씬·폰트·음악을 재사용하고 신규 연출은 런타임 도형으로 작성했습니다. 이번 변경에 외부 가구·장식 에셋 다운로드는 없습니다.

- 캠페인: PlayerPrefs `LightsOut.Rent.v3`, JSON `lightsout-rent-save.json`
- 영구 진행: PlayerPrefs `LightsOut.Permanent.v1`, JSON `lightsout-permanent-save.json`
- 저장 구조: 외부 게임 저장 v3 → 캠페인 v2·작업 모델 v4, 영구 진행 v1·방 작업 진행도는 별도 데이터
- 저장 내용: 위치·DAY·시작 기회·시간·현재 계획·정산·룰렛·방·콤보·스킬·액세서리 효과 복사본·전파·난수·작업 진행도

기존 작업 저장 v2/v3의 20/22개 스킬, 이전 v4의 24개 스킬을 25개로 옮깁니다. 이전 캠페인 v1은 현재 DAY의 옛 건물·시간·월세를 유지하며 다음 DAY부터 새 계획을 적용합니다. 실제 이전 저장의 **DAY 2 / 5층 × 4열 / 기회 4회 사용 / 보유금 189.25 / 미정산 수입 105 / 월세 273**을 초기화하지 않습니다. 이전 300층 이동 캠페인과 클릭형 저장 키는 별도로 보존합니다.

## 검증 상태

이번 버전의 Editor 검사 **38개 통과, 실패 0개**: 이동·수직 11개, 월세·시간·룰렛 15개, DAY·작업 시간·액세서리·저장 이전 12개입니다. 실제 Mover의 시간 진행 검사에서 DAY 1의 40개 방을 **51.6초 / 80초**에 소등했습니다. 이것은 검사 입력의 결과이며 초보 사용자의 플레이 시간 측정은 아닙니다.

**전체 화면·로비 버튼·신규 상승 및 소등 피드백의 실제 Play Mode 화면 확인, 추가 성장 검사와 최종 콘솔 점검은 진행 중입니다.** 현재 이 항목을 완료로 보고하지 않습니다. 이전 버전의 실제 플레이·팝업 검증은 [PLAYTEST.md](PLAYTEST.md)에 구분하여 보존했습니다.

검사와 상세 규칙은 [RENT-RULES.md](RENT-RULES.md), 에셋 출처는 [ASSET-LICENSES.md](ASSET-LICENSES.md)를 참조하세요. 장기 월세·스킬·포인트 밸런스, 장시간 성능, 다양한 해상도, 완성 아트와 Steam 출시 연동은 후속 검토 대상입니다.
