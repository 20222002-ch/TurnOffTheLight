# 불 끄고 퇴근해! — Lights Out!

건물 안을 자유롭게 이동하면서 전등을 끄고 돈을 버는 Steam/PC용 Unity 2D 게임입니다. 플레이어에게는 밀린 월세가 있습니다. **단계마다 최대 5번의 제한 시간 근무를 수행하며, 월세를 갚으면 남은 돈과 강화를 가지고 다음 단계로 진출합니다.** 퇴근 때 이번 근무 수입을 그대로 받거나, 21칸 퇴근 룰렛에 걸 수 있습니다.

- 상태: 메인 개발 후보의 이동·제한 시간·월세·룰렛 MVP
- 프로젝트: `D:\unity_projects\TurnOffTheLight`
- 환경: Unity `6000.3.8f1`, URP, uGUI, Input System
- 기준일: **2026-10-14, 한국 시간**
- 이번 수정 범위: 기존 Unity 프로젝트 구현과 문서. 실행 파일 빌드, Notion 수정, GitHub 푸시는 수행하지 않음.

## 실행 방법

1. Unity Hub에서 기존 `TurnOffTheLight` 프로젝트를 엽니다.
2. **Lights Out → Open Game Scene** 또는 `Assets/LightsOut/Scenes/LightsOut.unity`로 메인 씬을 엽니다.
3. Play를 누르고 시작 안내를 확인합니다. HUD 기준 해상도는 1600 × 900입니다.
4. WASD 또는 방향키로 플레이어를 이동합니다. 켜진 방에 닿거나 지나가면 자동으로 소등됩니다.
5. 소등 완료 또는 시간 만료 후 메인 퇴근 정산 화면에서 수입을 받거나 별도 룰렛 창을 엽니다. 정산 후 월세 납부, 강화, 다음 근무 중에서 선택합니다.

현재 버전은 Unity Editor에서 실행합니다. 기존 씬, HUD, 플레이어 프리팹, 한국어 폰트, 음악과 효과음을 재사용했습니다. 예전 클릭형 실행 파일은 이번 버전의 실행 파일이 아닙니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 위·아래·왼쪽·오른쪽 자유 이동 |
| 두 방향 동시 입력 | 대각선 이동. 입력 길이를 제한해 속도 보정 |
| Space | 대시 해금 후 마지막 이동 방향으로 대시 |
| T / 스킬 트리 버튼 | 스킬 트리 열기·닫기. 근무 중에는 제한 시간도 일시 정지 |
| ESC / 설정 | 일시 정지 화면 열기·닫기 |
| 강화 카드 / 트리 강화 버튼 | 정산된 보유금으로 강화 구매 |
| 줌 인 / 줌 아웃 버튼 | 건물 카메라 거리 조정 |
| 스킬 트리의 휠 / 드래그 / 전체 보기 | 트리 확대·축소 / 이동 / 배율·위치 초기화 |
| 퇴근 정산 버튼 | 수입 받기, 별도 룰렛 창 열기, 월세 납부, 강화, 다음 근무 |
| 룰렛 창 버튼 | 이번 수입 걸고 돌리기 / 정산 화면으로 돌아가기 |

마우스는 UI 조작에 사용하며 방을 클릭해서 소등하지 않습니다. 중력, 점프, 낙하, 벽 충돌, 문·계단·엘리베이터는 사용하지 않습니다. 층 구분선을 자유롭게 통과할 수 있습니다. 설정·업무 안내·스킬 트리에서 이동과 제한 시간이 멈춥니다. 정산 화면에서 닫기 입력으로 만료된 근무에 복귀할 수 없으며, 룰렛 회전 중에는 T·ESC와 다른 선택을 잠급니다.

## 현재 플레이 구조

**제한 시간 근무 → 이동·접촉 소등 → 미정산 수입 누적 → 완료 또는 시간 만료로 기회 1회 사용 → 그대로 받기 / 룰렛 → 월세 납부 / 강화 / 다음 근무**

처음에는 **3층 × 층당 4개 방 = 12개 전등**, **제한 시간 30초**, **월세 160**으로 시작합니다. 기본 보상으로 건물 전체를 소등하면 **61.5**를 법니다. 초기 건물은 느린 이동으로도 완료할 수 있는 난이도를 목표로 합니다.

각 단계의 기회는 총 5회입니다. 불을 전부 꺼도, 전부 끄지 못하고 시간이 끝나도 1회가 차감됩니다. 다음 근무에서는 같은 단계의 방과 시간이 초기화됩니다. 보유금과 강화는 유지합니다.

월세를 일찍 갚거나 마지막 기회까지 기다릴 수 있습니다. 납부하면 **보유금에서 월세를 차감하고 잔액·강화를 다음 단계로 이월**합니다. 남은 기회는 다음 단계로 이월하지 않으며 다음 단계에서 새 5회를 받습니다. 마지막 근무 정산 후에도 월세가 부족하면 파산 화면이 나타납니다. 재시작하면 돈과 스킬을 초기화하고 1단계부터 시작합니다. 여섯 번째 근무는 없습니다.

| 단계 | 층수 | 제한 시간 | 월세 | 기본 보상으로 전체 소등한 수입 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 3 | 30초 | 160 | 61.5 |
| 2 | 5 | 30초 | 273 | 105 |

이후 층수는 8, 12, 18, 28, 42, 64, 96, 144, 216, 300층으로 증가합니다. 시간은 3단계부터 단계당 5초 늘어나며 최대 80초입니다. 월세도 단계에 따라 증가합니다. 이는 현재 MVP의 초기 밸런스이며 출시 수치로 확정한 값은 아닙니다. 상세 규칙과 수식은 [RENT-RULES.md](RENT-RULES.md)에 기록했습니다.

## 수입과 퇴근 룰렛

**보유금과 이번 근무의 미정산 수입을 분리합니다.** 근무 도중 얻은 돈은 퇴근 정산 전에는 강화에 사용할 수 없습니다. 이전 근무에서 이미 받은 보유금은 강화에 사용할 수 있습니다.

| 정산 선택 | 지급액 | 확률 |
| --- | --- | --- |
| 그대로 받기 | 이번 근무 수입 ×1 | 확정 |
| 룰렛 ×2 | 이번 근무 수입 ×2 | 10 / 21, 약 47.62% |
| 룰렛 ×0 | 이번 근무 수입 전액 손실 | 10 / 21, 약 47.62% |
| 룰렛 ×10 | 이번 근무 수입 ×10 | 1 / 21, 약 4.76% |

**퇴근 정산이 메인 화면이며, 이 화면에는 룰렛 휠을 배치하지 않습니다.** `룰렛 창 열기`를 누르면 별도 팝업이 약 0.4초 동안 페이드·확대되며 나타납니다. 준비 상태에서는 돈을 사용하지 않고 정산 화면으로 돌아갈 수 있습니다. 팝업의 `이번 수입 걸고 돌리기`를 눌러야 추첨·정산합니다.

룰렛은 동일한 크기의 21칸입니다. 화면에서는 **×2와 ×0을 번갈아 배치하고 ×10 한 칸을 추가**합니다. 저장과 추첨에 쓰는 슬롯 ID는 기존대로 0–9가 ×2, 10–19가 ×0, 20이 ×10입니다. 표시 위치만 일대일로 재배치했으며 확률은 바꾸지 않습니다. 기존 잔고를 걸거나 잃지 않고 한 근무에 한 번만 선택할 수 있습니다. 수입이 없으면 룰렛 버튼을 비활성화합니다.

돌리기를 누르면 게임 모델에서 결과와 지급액을 먼저 결정해 저장한 뒤 **수입 티켓 이동 0.9초 → 가속 0.75초 → 빠른 회전 1.1초 → 감속 3초 → 결과 공개 0.65초**, 총 약 **6.4초**의 연출을 재생합니다. 순환하는 테두리 조명, 포인터 반동, 중앙 맥동, 배경 어두워짐과 짧은 틱·저음 펄스로 긴장감을 더합니다. 같은 감속 규칙으로 저장된 결과 칸에 멈추며 재접속으로 다시 추첨하지 않습니다. 팝업을 닫기 전까지 뒤의 정산 화면 잔고 표시는 기존 값을 유지합니다. 결과를 확인하고 돌아오면 정산 화면을 갱신합니다. 작은 금액은 소수 부분을 그대로 표시하며 61.5를 62로 반올림하지 않습니다.

## 스킬 트리

각 계열에 5개씩 총 **20개 노드**가 있습니다. 별도 스킬 포인트 없이 정산된 **보유금**을 사용합니다. 상위 스킬은 표시된 선행 레벨을 달성하면 해금됩니다.

| 계열 | 색상 | 스킬 |
| --- | --- | --- |
| 이동 강화 | 노란색 | 이동속도 증가, 소등 범위 확장, 대시, 대시 거리 증가, 이동 중 보너스 수익 |
| 연쇄 강화 | 파란색 | 연쇄 소등, 연쇄 확장, 연쇄 가속, 과부하, 블랙아웃 |
| 수직 돌파 | 보라색 | 수직 소등, 층 전체 정전, 수직 관통, 상승 가속, 초고속 돌파 |
| 자동화 | 초록색 | 자동 스위치, 자동 소등 속도, 자동 층 정전, 자동 연쇄, 완전 자동화 |

노드 연결선, 현재/최대 레벨, 잠금 상태, 현재·다음 효과, 가격과 선행 조건을 표시합니다. 대시는 이동 경로 전체를 검사합니다. 연쇄·수직·자동화는 중복 보상과 무한 전파를 방지합니다. 소수 자동화 처리량은 누적하며 0.2개/초는 약 5초마다 한 개를 소등합니다.

정산 전과 파산 상태에서는 강화를 구매할 수 없습니다. 마지막 기회 후에도 강화 화면을 열 수 있지만 월세 납부금을 부족하게 만드는 구매는 차단합니다. `자동 층 정전`의 기본 효과는 자동 소등 30회마다 추가 1층이며, 레벨별 추가 효율은 검토 중입니다.

## 저장

현재 저장 키는 `PlayerPrefs`의 **`LightsOut.Rent.v3`**입니다. JSON 복사본은 `Application.persistentDataPath/lightsout-rent-save.json`입니다. 현재 불러오기는 PlayerPrefs를 사용합니다.

캐릭터 위치, 단계·기회·남은 시간, 정산 상태와 룰렛 결과, 방 상태, 보유금·미정산 수입, 스킬, 난수 상태와 전파·자동화 상태를 저장합니다. 약 8초 간격과 구매·정산·월세 납부·명시적 저장·종료 시 저장합니다. 손상된 데이터는 일부만 적용하지 않고 거절합니다.

이전 이동 버전의 `LightsOut.Movement.v2`와 클릭 버전의 `LightsOut.Save.v1`은 별도 키로 유지합니다. 과거 300층 근무 저장을 새 월세 진행으로 자동 변환하지 않습니다.

## 검증과 다음 작업

- 이번 UI 수정에서 월세·시간·룰렛 모델 회귀 검사 **15개 통과, 실패 0개**. 기존 이동 검사 11개 통과 기록은 유지합니다.
- 별도 룰렛 팝업과 6.4초 연출의 Play Mode 검증을 완료했습니다. 실제 버튼으로 창 열기·돌리기·복귀를 확인했고, 준비 상태에서 닫으면 저장 JSON이 변하지 않았습니다. 21칸의 교대 표시 매핑도 일대일로 확인했습니다.
- 준비·회전 중 결과 숨김, 메인 잔고 표시 고정과 입력·중복 추첨 차단을 확인했습니다. 이번 수입 61.5의 ×10은 615를 지급해 기존 보유금 100이 715가 됐고 정확한 결과 칸에 멈췄습니다. 마지막 기회의 ×0은 기존 보유금 100을 유지하며 파산으로 처리하고, 팝업을 닫은 뒤 실패 정산 화면으로 전환했습니다.
- 음량 0에서 오디오 소스 4개가 모두 0이며, 연출 종료 후 음악 음량 0.18 복귀를 확인했습니다. 최신 컴파일·실행 오류는 0개입니다. Unity AI Account 외부 서비스 접근 지연 경고 1개는 게임 코드 오류와 별도로 남아 있습니다.
- 아래 실제 입력·저장 복원 기록은 이전 월세 MVP에서 수행한 검사입니다. 새 팝업 검증은 [PLAYTEST.md](PLAYTEST.md)의 최신 기록과 구분합니다.
- 검사 메뉴: **Lights Out → Run movement and vertical checks**, **Lights Out → Run rent, timer and roulette checks**. 독립 검증 상태를 사용하며 플레이어 저장을 변경하지 않습니다.
- 실제 키보드로 첫 건물 12개 전등을 소등하여 5.35초에 완료, 24.65초 잔여 시간과 미정산 수입 61.5를 확인했습니다. 실제 정산·50원 이동 강화 구매도 확인했습니다.
