# 불 끄고 퇴근해! — Lights Out!

건물 내부를 자유롭게 이동하면서 방의 불을 끄고, 성과급으로 이동·연쇄·수직·자동화 능력을 강화하는 Steam/PC용 Unity 2D MVP입니다. 방에 닿거나 지나가면 별도 클릭 없이 소등됩니다. 아래층에서 위층으로 진행하며, 성장할수록 여러 방과 층이 연속으로 어두워지는 경험을 검증합니다.

- 상태: 메인 개발 후보의 이동 기반 MVP
- 프로젝트: `D:\unity_projects\TurnOffTheLight`
- 환경: Unity `6000.3.8f1`, URP, uGUI, Input System
- 기준일: **2026-10-14, 한국 시간**
- 이번 수정 범위: 기존 Unity 프로젝트의 코드·씬·프리팹·리소스 수정. Notion 작업과 실행 파일 빌드는 수행하지 않음.

## 실행 방법

1. Unity Hub에서 기존 `TurnOffTheLight` 프로젝트를 엽니다.
2. `Assets/LightsOut/Scenes/LightsOut.unity` 씬을 엽니다.
3. Play를 누르고 Game 창을 선택합니다. HUD 기준 해상도는 1600 × 900입니다.
4. WASD 또는 방향키로 사각형 플레이어를 이동합니다. 켜진 방에 접촉하면 전등이 꺼지고 성과급이 지급됩니다.

기존 씬과 HUD를 재사용했습니다. 이전 클릭형 프로토타입의 마우스 소등 방식은 현재 메인 씬에서 사용하지 않습니다. 이전에 생성된 클릭형 실행 파일은 이번 이동 방식의 검증 자료가 아닙니다. 현재 버전은 Unity Editor에서 실행합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W / ↑ | 위로 이동 |
| A / ← | 왼쪽으로 이동 |
| S / ↓ | 아래로 이동 |
| D / → | 오른쪽으로 이동 |
| 두 방향 동시 입력 | 대각선 이동. 벡터 길이를 제한해 속도 보정 |
| Space | 대시 스킬 해금 후 마지막 이동 방향으로 대시 |
| T 또는 스킬 트리 버튼 | 스킬 트리 열기. 열린 상태에서 T로 닫기 |
| ESC 또는 설정 | 일시 정지 화면 열기. 열린 화면에서 ESC로 닫고 재개 |
| 강화 카드 / 스킬 트리 강화 버튼 | 성과급을 지급하고 스킬 강화 |
| 화면의 줌 인 / 줌 아웃 버튼 | 건물 카메라 거리 조정 |
| 스킬 트리의 휠 / 드래그 | 트리 확대·축소 / 이동 |
| 스킬 트리의 전체 보기 | 확대 배율과 이동 위치 초기화 |

마우스는 UI 조작에 사용합니다. 전등 클릭은 소등 입력이 아닙니다. 중력, 점프, 낙하, 벽 충돌, 문·계단·사다리·엘리베이터는 사용하지 않습니다. 층 사이의 선은 시각적 구분이며 모든 방향으로 자유롭게 이동합니다.

설정, 업무 안내, 스킬 트리에서는 이동·대시 입력과 소등 진행이 일시 정지됩니다. 스킬 트리에서는 정지된 상태로 강화할 수 있습니다. 새 게임은 확인 화면을 거치며, 소리 설정과 저장 기능은 기존 흐름을 유지합니다.

## 현재 플레이 구조

**이동·방 접촉 → 소등·성과급 → 스킬 강화 → 넓어진 범위·대시·연쇄·수직 소등 → 더 높은 층 → 자동화**

건물은 논리적으로 **300층 × 층당 4개 방 = 1,200개 전등**으로 구성합니다. 각 방은 사각형과 전등 하나로 표현합니다. 꺼진 방은 남색으로 변하고 소등 완료 상태를 유지합니다. 같은 방을 재방문해도 성과급을 중복 지급하지 않습니다.

진행 경계인 가장 낮은 미완료 층을 기준으로 위쪽 층의 이동·표시 범위를 확장합니다. 먼저 소등한 위층의 상태도 유지하며, 아래쪽의 미완료 층을 완료하면 이미 완료된 층을 건너뛰어 진행합니다. 모든 300층을 소등하면 퇴근 화면이 나타납니다. 다음 건물에서는 방 상태와 위치를 초기화하고 스킬·보유 성과급·누적 기록을 유지합니다. 이는 현재의 반복 근무 구조이며, 별도 환생 재화 시스템은 구현하지 않았습니다.

| 시작 층 | 성장 구역 |
| ---: | --- |
| 1층 | 작은 사무실 |
| 13층 | 사무동 |
| 37층 | 대형 빌딩 |
| 73층 | 복합 건물 |
| 121층 | 야간 도시 |
| 201층 | 도시 전력망 |

구역 명칭과 층·스킬 가격·발동 확률은 현재 MVP의 테스트 값입니다. 초보자의 전체 플레이 시간이나 최종 출시 밸런스로 확정한 값이 아닙니다.

## 스킬 트리

각 계열에 5개씩 총 **20개 노드**를 배치했습니다. 별도 스킬 포인트 없이 소등으로 얻은 **성과급**을 사용합니다. 기본 스킬은 처음부터 강화 가능하며, 상위 스킬은 선행 스킬의 표시된 레벨을 달성하면 해금됩니다.

| 계열 | 색상 | 스킬 |
| --- | --- | --- |
| 이동 강화 | 노란색 | 이동속도 증가, 소등 범위 확장, 대시, 대시 거리 증가, 이동 중 보너스 수익 |
| 연쇄 강화 | 파란색 | 연쇄 소등, 연쇄 확장, 연쇄 가속, 과부하, 블랙아웃 |
| 수직 돌파 | 보라색 | 수직 소등, 층 전체 정전, 수직 관통, 상승 가속, 초고속 돌파 |
| 자동화 | 초록색 | 자동 스위치, 자동 소등 속도, 자동 층 정전, 자동 연쇄, 완전 자동화 |

스킬 트리는 노드 연결선, 현재/최대 레벨, 잠금·강화 가능·완료 상태를 표시합니다. 노드를 선택하면 현재 효과, 다음 효과, 강화 비용, 선행 조건을 확인할 수 있습니다. 이동 강화는 기존 클릭 강화를 대체했습니다.

- 소등 범위 확장과 연쇄를 조합하면 접촉 주변의 방으로 순차 소등이 퍼집니다.
- 대시 이동 경로의 모든 방을 검사하며 수직·연쇄 효과와 결합합니다.
- 자동 스위치는 소수 처리량을 누적합니다. 예를 들어 0.2개/초는 약 5초마다 1개를 처리합니다.
- 연쇄·수직·자동 연쇄는 동일 방의 중복 처리와 무한 재발동을 막습니다.
- 확률은 0–100% 범위로 제한하며 전파·자동화 간격은 0 이하가 되지 않도록 제한합니다.

`자동 층 정전`의 기본 효과는 자동 소등 30회마다 추가 1층입니다. 현재 각 레벨의 추가 효율 차이는 검토 중이며, 세부 강화 효과를 확정한 기능으로 해석하지 않습니다.

모든 300층을 GameObject로 생성하지 않습니다. **48개 층의 렌더 풀**을 미리 만들고 카메라 주변 층에 재배치하며, 화면 밖 층은 비활성화합니다. 방 상태와 표시를 분리하여 다시 보이는 층에도 이전 소등 상태를 적용합니다. 고속 이동 판정은 이전·현재 위치 사이의 전체 선분을 검사해 통과한 방을 놓치지 않도록 구성했습니다.

카메라는 캐릭터를 부드럽게 추적하며 높은 층에서 점차 줌아웃합니다. HUD는 화면에 고정합니다. 방 내부 가구, 인테리어, NPC와 복잡한 걷기 애니메이션은 이번 MVP에 포함하지 않습니다. 기존 야간 팔레트, 소등 색 변화, 금액 피드백, 음악, 한국어 폰트와 주변 HUD를 재사용합니다.

## 저장

현재 저장 키는 `PlayerPrefs`의 **`LightsOut.Movement.v2`**입니다. 약 8초 간격, 스킬 구매, 명시적 저장과 종료·비활성화 때 저장합니다. 캐릭터 위치와 모델의 방 상태, 스킬, 성과급, 진행, 난수 상태, 대기 중 전파, 소수 자동화 누적량을 기록합니다.

JSON 복사본은 `Application.persistentDataPath/lightsout-movement-save.json`입니다. 현재 불러오기는 PlayerPrefs를 사용합니다. 파일을 읽을 때 유효하지 않은 위치는 시작 위치로 보정하며, 손상된 모델은 거절합니다.

이전 클릭형의 `LightsOut.Save.v1`과 별도 키를 사용합니다. 기존 클릭형 저장을 이동형 진행으로 자동 변환하지 않습니다.

## 검증과 다음 작업

- 에셋 출처·라이선스: [ASSET-LICENSES.md](ASSET-LICENSES.md).

다음 우선순위는 20개 스킬의 성장 속도와 가격 조정, 자동 층 정전의 레벨별 효과 결정입니다. 300층 전체를 사람이 플레이한 시간, 다양한 해상도·저사양 PC의 성능, Steam SDK·도전 과제·출시 연동은 별도 검토 대상입니다. 이번 이동 수정에서는 실행 파일을 빌드하지 않았습니다.
