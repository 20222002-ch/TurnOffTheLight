# 불 끄고 퇴근해! — DAY·소등·월세·영구 성장 규칙

기준일: **2026-10-14, 한국 시간**
대상: 기존 `TurnOffTheLight` Unity 프로젝트
범위: 구현·문서·Editor 검증. 실행 파일 빌드, Notion 작업, GitHub 푸시는 수행하지 않습니다.

## 1. DAY와 근무 상태

**근무 준비 → 근무 → 퇴근 정산 → 그대로 받기 / 룰렛 → 월세 납부 / 일반 강화 / 다음 근무**

| 상태 | 규칙 |
| --- | --- |
| Lobby · 근무 준비 | 새 DAY 또는 게임오버 후 재시작. 기회 사용 0, 이동·시간 정지. 액세서리 변경 가능 |
| Working · 근무 | 시작 시 기회 1회 사용. 기본 1초 작업 소등, 수입 미정산 |
| Checkout · 퇴근 정산 | 완료 또는 시간 만료. 기회를 추가 차감하지 않음. 수입 정산부터 선택 |
| BetweenAttempts · 정산 완료 | 월세 납부·일반 강화·같은 DAY 다음 근무 선택. 액세서리 교체 불가 |
| Bankrupt · 게임오버 | 다섯 번째 근무 정산 후 월세 부족. 여섯 번째 근무 불가 |

기회는 DAY마다 총 5회이며 **근무를 시작할 때** 차감합니다. 불을 전부 끄든 시간 내에 끝내지 못하든 이미 사용한 기회는 반환하지 않습니다. 중복 시작·중복 종료·중복 정산은 거절합니다. 완료·만료 후에는 이동·자동화·예약 전파가 멈춰 추가 수입을 만들 수 없습니다.

근무에는 자유로운 WASD·방향키 이동을 사용합니다. 마우스 방 클릭, 중력, 낙하, 벽 충돌은 없습니다. 진행 화면은 전체 인게임 중심으로 구성하며 상시 장부·강화 대시보드는 숨깁니다. 작업 게이지·소등·콤보 피드백·마지막 5초는 필요한 진행 표시입니다. 정산 화면과 별도 룰렛 창은 유지합니다. 메뉴·스킬 트리에서 시간과 이동을 정지하며 룰렛 중에는 다른 행동을 잠급니다.

## 2. 건물과 기본 경제

| DAY 키프레임 | 열 | 층 | 전체 방 | 시간 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 20 | 2 | 40 | 80초 |
| 5 | 14 | 5 | 70 | 90초 |
| 10 | 9 | 12 | 108 | 100초 |
| 20 | 6 | 28 | 168 | 110초 |
| 40 | 4 | 60 | 240 | 120초 |

중간 DAY는 키프레임 보간값을 사용합니다. 열 수는 올림, 층 수는 반올림합니다. DAY 40 이후 기본값은 4열·하루 +2층·하루 +1초, 최대 150초입니다. 논리 층수 상한은 4,096입니다. 기본 방 폭 2.4를 사용하여 초반에는 낮고 가로로 긴 대형마트, 후반에는 좁고 높은 빌딩이 됩니다. 폭 축소는 추가로 적용할 수 있습니다.

0부터 시작하는 층 `f`와 현재 계획의 열 수 `C`, 층수 `F`를 사용합니다.

- 전등 기본 보상: `5 + 0.125 × f`
- 기본 전체 소등 수입: `C × F × (5 + 0.125 × (F - 1) / 2)`
- 월세 기준액: 키프레임마다 계산한 기본 전체 소등 수입을 DAY 사이에서 연속 보간. 열·층 반올림으로 생기는 수입 변동과 분리
- 월세: 위 기준액 × 현재 계획의 월세 배율을 올림. 기본 배율 2.6
- DAY 1: 기본 수입 **202.5**, 월세 **527**
- 실제 보상에는 소등 당시 콤보 배율과 이동 수입 스킬을 적용하고, 퇴근 전 배지 보너스를 추가
- 월세의 기본 수입에는 콤보·액세서리·룰렛을 넣지 않음

일반적인 소등 보상·실제 형상의 전체 기본 수입·월세 기준액을 구분합니다. 콤보가 유지된 실제 전체 소등 금액은 기본 수입보다 큽니다. 월세 기준액은 키프레임 사이에서 연속 증가하도록 보간하여 열·층의 정수화 때문에 월세가 감소하지 않도록 합니다. 기본값의 신규 DAY 2 월세는 634, DAY 5는 956, DAY 10은 1,598입니다.

DAY 계획은 저장된 값을 사용하므로 현재 DAY 도중 Inspector 수치를 변경하거나 재접속해도 건물·시간·월세가 자동 교체되지 않습니다. 다음 DAY부터 새 설정을 사용합니다. 기존 저장의 옛 DAY 2 월세 273은 새 기준액으로 바꾸지 않습니다.

## 3. 작업 진행도와 콤보

켜진 방 안에서 기본 **1초** 동안 작업하면 소등합니다. 다른 방으로 이동했을 때 진행도는 기본 **1.5초** 동안 유지됩니다. 그 안에 돌아오면 이어서 진행하고, 보존 시간이 지나면 해당 방의 미완료 작업은 사라집니다. 장갑은 이 보존 시간을 늘립니다. 일시 정지·정산·로비에서는 작업 시간과 보존 시간도 진행하지 않습니다.

소등 속도 강화의 레벨 0–6 기본 소요 시간은 **1 / 0.8 / 0.65 / 0.5 / 0.35 / 0.2 / 0초**입니다. 이동속도와 독립된 강화이며 마지막 레벨은 이동 선분에서 접촉한 모든 방을 즉시 처리합니다. 고속 대시·상승에서 중간 방의 접촉을 누락하지 않습니다.

불이 켜져 있다가 새로 꺼지는 이벤트마다 콤보를 1 올리고 기본 유지 시간 4초를 갱신합니다. 직접·연동·연쇄·자동 소등 모두 새 방이면 인정합니다.

| 콤보 | 해당 소등의 수익 배율 |
| ---: | ---: |
| 1 | ×1 |
| 5 | ×1.2 |
| 10 | ×1.5 |
| 20 | ×2 |

각 기준 이상에서 다음 기준 전까지 같은 배율입니다. 콤보가 높아졌다고 이미 지급한 수입을 소급하여 올리지 않습니다. 유지 시간이 끝나면 현재 콤보는 0이 되고 최고 콤보는 해당 근무 종료까지 남습니다. 같은 꺼진 방으로 콤보·보상을 반복 획득할 수 없습니다.

## 4. 일반 스킬

현재 25개 스킬의 ID 0–19는 보존합니다. 기존 20–21의 가로 축소·수직 돌파에 22–24를 추가했습니다.

| ID | 스킬 | 기본 해금·효과 |
| ---: | --- | --- |
| 0 | 이동속도 증가 | DAY 1, 이동 강화 |
| 22 | 소등 속도 강화 | DAY 1, 작업 시간 단축, Lv.6 즉시 소등 |
| 23 | 상층 연동 소등 | DAY 1, 직접 소등 시 같은 위치 위쪽 1/2/3층 즉시 소등 |
| 2 | 대시 | DAY 5와 기존 선행 조건 |
| 5 | 연쇄 소등 | DAY 10과 기존 선행 조건 |
| 11 | 층 전체 정전 | DAY 10, 확률 기반 수직 패시브 |
| 20 | 건물 가로 축소 | DAY 10·수직 소등 Lv.2, 7%/레벨, 최대 35% |
| 24 | 층 완료 정전 | DAY 10·층 전체 정전 Lv.2, 위아래 인접층 1/2/3개 방 |
| 12 | 수직 관통 | DAY 15와 기존 선행 조건 |
| 15 | 자동 스위치 | DAY 15와 기존 선행 조건 |
| 21 | 수직 돌파 | DAY 20·수직 관통 Lv.3, R 액티브 |
| 9 / 19 | 블랙아웃 / 완전 자동화 | DAY 30 / DAY 40과 기존 선행 조건 |

전체 25개는 이동 6개·연쇄 5개·수직 9개·자동화 5개로 구성하며 상세 가격·선행 조건은 게임의 현재·다음 효과 패널을 따릅니다. DAY 조건과 스킬 선행 조건을 동시에 만족해야 새 구매가 가능합니다. 이전 저장에서 이미 가진 스킬을 DAY 조건만으로 제거하지 않습니다.

상층 연동은 직접 작업 완료마다 한 번만 발동하고, 연동 소등이 다시 같은 연동을 호출하지 않습니다. 반지도 직접 완료에서 한 번만 발동합니다. 층 완료 정전은 다음 전파 간격으로 예약하고 동일 원점의 완료 확산을 최대 2회로 제한합니다. 꺼진 방·방문한 방은 중복 지급하지 않으며 전체 큐·프레임 처리량도 제한합니다.

수직 돌파는 위로 8/12/16층, 약 0.28초 상승, 재사용 14/12/10초입니다. 가로 축소는 외형·접촉 영역·이동 경계를 함께 바꾸지만 논리 방 수·방 ID·기본 보상은 유지합니다. 상승 중에는 민트·금색 궤적과 조각·잔상을 표시합니다.

정산 전과 게임오버 상태에서는 일반 강화를 구매할 수 없습니다. 마지막 정산 후에도 월세 예비금을 부족하게 만드는 구매는 거절합니다. 자동 층 정전의 레벨별 추가 효율은 아직 별도 검토 사항입니다.

## 5. 보유금·정산·월세

| 금액 | 의미 |
| --- | --- |
| 보유금 | 이전 근무에서 정산한 금액. 월세·일반 강화에 사용 |
| 미정산 수입 | 이번 근무 수익과 퇴근 배지 보너스. 정산 전 사용할 수 없음 |
| 관리인 포인트 | 액세서리용 영구 재화. 일반 강화·월세 재화와 분리 |

월세는 **보유금에서 차감하고 잔액·일반 스킬을 다음 DAY로 이월**합니다. 남은 기회는 이월하지 않고 새 DAY에 5회를 받습니다. 미리 갚거나 남은 기회 동안 강화·추가 수입을 선택할 수 있습니다. 마지막 기회 정산 후에도 월세가 충분하면 납부할 수 있습니다.

정산은 그대로 받기 ×1 또는 룰렛 중 한 번만 선택합니다. 예를 들어 기존 보유금 20·이번 수입 30이면 ×1 결과 50, NOTHING 결과 20, ×2 결과 80, ×10 결과 320입니다. 기존 보유금은 룰렛에 걸지 않습니다. 미정산 돈을 먼저 써서 손실을 피할 수 없습니다.

다섯 번째 정산까지 월세를 충당하지 못하면 게임오버입니다. 재시작하면 DAY 1 로비, 보유금 0·일반 스킬 0·새 5회가 되지만 포인트·액세서리·장착·최고 완납 DAY는 유지합니다.

## 6. 퇴근 룰렛

| 결과 | 기본 실제 확률 | 저장 슬롯 |
| --- | ---: | --- |
| NOTHING · ×0 | 60% | 10–19 |
| ×2 | 37% | 0–9 |
| ×10 | 3% | 20 |

먼저 결과 종류의 가중 확률로 추첨하고, ×0·×2 안에서는 각각 10개 저장 슬롯에 균등 분배합니다. 표시 칸의 각도와 면적도 슬롯의 실제 확률을 사용합니다. ×2와 NOTHING은 섞어서 배치하고 ×10 한 칸을 유지합니다. **21칸 동일 확률과 이전 10/21·10/21·1/21 규칙은 현재 규칙이 아닙니다.** Inspector의 가중치는 정규화하며 위 확률은 기본 설정입니다.

메인 정산에 휠을 넣지 않고 별도 팝업 버튼을 둡니다. 열기만 하면 베팅하지 않아 준비 상태에서 닫을 수 있습니다. 돌리기를 누르면 결과·지급을 저장하고 티켓 이동 0.9초, 가속 0.75초, 고속 회전 1.1초, 감속 3초, 결과 공개 0.65초를 재생합니다. 팝업 열기 약 0.4초는 이 합계 6.4초와 별개입니다.

준비·회전 중 결과를 숨기고 배경 메인 잔고를 고정합니다. 조명·포인터·틱·저음 펄스를 사용하며, 모든 결과에 같은 감속 규칙을 적용합니다. 돌아가기를 누른 뒤 메인 장부를 갱신합니다. 회전 중 입력 우회·중복 추첨을 차단하고 저장된 이전 결과는 재추첨하지 않습니다.

## 7. 포인트·액세서리·로비

이전에 납부한 최고 DAY보다 높은 DAY를 처음 완납할 때 포인트를 받습니다.

| 납부 시 남은 기회 | 첫 완납 포인트 |
| ---: | ---: |
| 3–4 | 4 |
| 2 | 3 |
| 1 | 2 |
| 0 | 1 |

수식은 `1 + min(3, 남은 기회)`입니다. 기록된 최고 DAY 이하에서는 반복 지급하지 않습니다. 게임오버 후 낮은 DAY를 반복하여 포인트를 늘리는 방식은 차단합니다.

최대 3개를 장착하고 **새 DAY / 재시작 로비**에서만 변경합니다. 같은 DAY 정산 후 다음 근무에서는 바꾸지 않습니다. 시작 시 장착 효과를 복사하여 진행 중 장비와 효과가 달라지지 않도록 합니다.

| 액세서리 | Lv.1 / 강화 |
| --- | --- |
| 작업 장갑 | 진행도 보존 +0.5초/레벨 |
| 야간 운동화 | 콤보당 이동속도 +1%, 추가 레벨마다 콤보당 +0.5%p, 최대 20콤보 |
| 관리인 열쇠 | 시작 자동 소등 3개, 레벨마다 추가 +2개, Lv.5 11개 |
| 전기 반지 | 직접 소등 시 주변 1개 소등 확률 10%/레벨, Lv.5는 탐색 범위 2칸 |
| 성과 배지 | 최고 콤보 × 0.25/레벨을 근무 종료 전에 한 번 가산 |

시작 열쇠는 꺼진 방을 재보상하지 않고, 반지는 자신을 재귀 발동하지 않습니다. 배지는 미정산 수입에 가산하므로 룰렛에도 함께 적용됩니다. 미장착 효과는 0입니다. 기본 상한 Lv.5, 최초 가격 3/4/5/5/6 포인트, 가격 성장률 1.8이며 설정 자산에서 조정합니다.

## 8. 설정·저장·렌더 제한

설정 자산은 `Assets/LightsOut/Resources/LightsOutBalanceSettings.asset`입니다. DAY 형상·시간·월세 배율·소등 시간·스킬 DAY·콤보·룰렛 가중치·액세서리 비용을 Inspector에서 조정합니다. 현재 DAY의 `columns/floors/roomWidth/duration/rentDue`는 캠페인 저장에 고정합니다.

| 저장 | 버전 / 위치 |
| --- | --- |
| 게임 외부 저장 | v3, PlayerPrefs `LightsOut.Rent.v3`, `lightsout-rent-save.json` |
| 캠페인 | v2, 현재 DAY 계획·시작 기회·정산·룰렛과 작업 JSON |
| 작업 모델 | v4, 가변 열·층·폭·25스킬·콤보·장비 효과·예약 전파 |
| 영구 진행 | v1, PlayerPrefs `LightsOut.Permanent.v1`, `lightsout-permanent-save.json` |
| 미완료 작업 진행도 | Mover 데이터로 게임 외부 저장의 `workProgress`에 별도 보관 |

파일은 `Application.persistentDataPath`에 쓰며 불러오기는 PlayerPrefs를 사용합니다. 손상 데이터는 유효 상태를 일부 덮어쓰지 않고 거절합니다. 이전 작업 v2/v3의 20/22스킬과 이전 v4의 24스킬을 25스킬로 확장합니다.

이전 캠페인 v1은 현재 DAY의 옛 층수·열·폭·시간·월세를 유지합니다. 예전 Working의 종료 횟수 저장만 현재 시작 횟수로 +1 변환하며 정산 횟수는 그대로입니다. 실제 저장 **DAY 2·5층 × 4열·4회 사용·보유금 189.25·이번 수입 105·월세 273**은 보존합니다. 이 DAY의 다음 기회도 같은 옛 계획을 사용하고 월세 납부 뒤 새 DAY부터 새 형상을 적용합니다.

표시는 48개 층 풀과 층별 20개 방 슬롯을 재사용하고 가로 화면 밖은 숨깁니다. 논리 상태 상한 4,096층을 한꺼번에 렌더링하지 않습니다. 보상 팝업 24개, 스파크 48개, 수직 돌파 12개 SpriteRenderer, 원형 작업 게이지 32개 구간으로 연출을 제한합니다. 신규 연출은 기존 도형과 자체 런타임 기하를 사용하며 외부 가구·장식 다운로드는 없습니다.

### 이전 월세 MVP에서 실제 회전 중 저장 복원

별도의 검증용 상태에서 슬롯 20의 ×10 결과가 나온 직후, 회전이 끝나기 전에 실제 저장 파일과 PlayerPrefs에 **정산 완료·보유금 50·슬롯 20·배수 10**이 기록된 것을 확인했습니다.

이 상태로 Unity **Stop → Play**를 수행한 후 아래를 확인했습니다.

- 정산 후 상태 `BetweenAttempts`, 사용 기회 1회, 보유금 50 복원
- 슬롯 20, 배수 10 유지
- 회전 상태 `IsSpinning=false`, 휠 각도 약 342.857°로 즉시 정렬
- 게임 일시 정지 `IsPaused=true`: 종료된 근무에 복귀하지 않음
- 재추첨 요청 거절

마지막 컴파일은 오류 0개로 성공했습니다. 이 검증은 전체 게임의 장기 밸런스나 고층 전체 수동 플레이 완료를 증명하지 않습니다.

최종 실행 콘솔 오류와 누락된 스크립트는 0개입니다. Unity AI 패키지의 Account API 연결 시간 초과 경고 1개는 게임 로직과 별도로 남아 있습니다. 검증용 저장 데이터는 작업 전 상태로 복원했으며 테스트 수입·강화를 남기지 않았습니다.
