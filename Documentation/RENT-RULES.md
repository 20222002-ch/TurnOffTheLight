# 불 끄고 퇴근해! — DAY·수익·월세·영구 성장 규칙

기준일: **2026-10-14, 한국 시간**
대상: 기존 `TurnOffTheLight` Unity 프로젝트
범위: 구현·문서·Editor 검증. 실행 파일 빌드, Notion 작업, GitHub 푸시는 수행하지 않습니다.

## 1. DAY와 근무 상태

**근무 준비 → 근무·소등·영구 XP → 근무 종료 정산 → ×1 확정 / 선택 룰렛 → 월세 납부 / 강화 / 다음 근무**

| 상태 | 규칙 |
| --- | --- |
| Lobby · 근무 준비 | 새 DAY 또는 게임오버 후 재시작. 기회 사용 0, 이동·시간 정지. 액세서리 변경 가능 |
| Working · 근무 | 시작 시 기회 1회 사용. 소등 수입은 미정산, XP는 소등 시 영구 누적 |
| Checkout · 근무 종료 정산 | 완료 또는 시간 만료. 기회를 다시 차감하지 않음. 이번 수입 선택 가능 |

| Bankrupt · 게임오버 | 다섯 번째 정산 후 월세 부족. 여섯 번째 근무 불가 |

기회는 DAY마다 총 5회이며 **근무를 시작할 때** 차감합니다. 완료하거나 시간 내에 끝내지 못해도 이미 사용한 기회는 반환하지 않습니다. 중복 시작·종료·정산은 거절합니다. 정산·로비·일시 정지에서는 이동·자동화·작업 진행·유지 시간·예약 전파가 멈춥니다.

근무에는 WASD·방향키의 자유 이동을 사용합니다. 마우스 방 클릭, 중력, 낙하, 벽 충돌은 없습니다. 전체 인게임 화면에 작업 게이지·소등 보상·콤보·마지막 5초 등 필요한 피드백을 표시하며 상시 장부·업그레이드 대시보드는 숨깁니다.

## 2. 건물과 월세 기준

| DAY 키프레임 | 열 | 층 | 전체 방 | 기본 시간 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 20 | 2 | 40 | 80초 |
| 5 | 14 | 5 | 70 | 90초 |
| 10 | 9 | 12 | 108 | 100초 |
| 20 | 6 | 28 | 168 | 110초 |
| 40 | 4 | 60 | 240 | 120초 |

중간 DAY는 키프레임을 보간하여 열 수는 올림, 층 수는 반올림합니다. DAY 40 이후 기본값은 4열·하루 +2층·하루 +1초이며 기본 제한 시간 상한은 150초, 논리 층수 상한은 4,096입니다. 기본 방 폭은 2.4로 초반은 낮고 넓은 대형마트, 후반은 좁고 높은 빌딩입니다. 가구·NPC·복잡한 실내 장식은 추가하지 않습니다.

0부터 시작하는 층 `f`, 현재 계획의 열 `C`, 층 `F`를 사용합니다.

- 방 기본 수익: `B = 5 + 0.125 × f`
- 전체 기본 수입: `C × F × (5 + 0.125 × (F - 1) / 2)`
- 월세 기준액: 키프레임별 전체 기본 수입을 DAY 사이에서 연속 보간
- 월세: 기준액 × 현재 계획의 배율을 올림. 기본 배율 2.6
- DAY 1 기본 수입 202.5 / 월세 527. 신규 DAY 2 월세 634, DAY 5는 956, DAY 10은 1,598

등급·무작위·돈다발·특수·콤보·스킬·액세서리·룰렛을 월세 기준액에 다시 더하지 않습니다. 연속 보간은 열·층 반올림 때문에 다음 DAY 월세가 내려가는 것을 방지합니다. 현재 DAY의 형상·시간·월세는 저장된 계획을 유지하고 새 설정은 다음 DAY에 적용합니다. 옛 계획의 월세 273 사례는 이전 버전의 데이터이며 모든 현재 DAY 2를 뜻하지 않습니다.

## 3. 작업 시간·즉시 추첨·콤보

방 안에서 기본 1초 작업하면 소등합니다. 다른 방으로 이동해도 기본 **1.5초** 동안 해당 방의 미완료 진행도를 보존합니다. 그 안에 재진입하면 이어서 진행하며 유지 시간을 넘기면 사라집니다. 절전 장갑은 유지 시간을 늘립니다. 큰 범위에서도 가까운 한 대상에 시간 작업을 적용하고 여러 겹친 방이 한 번에 완료되지 않도록 합니다.

| 소등 속도 강화 레벨 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 기본 소요 시간 | 1초 | 0.8초 | 0.6초 | 0.45초 | 0.3초 | 0.2초 | 0.15초 |

최종 속도도 기본 최소 **0.15초**를 유지합니다. 최소 시간 설정 범위는 0.1–0.2초이며 0을 입력해도 최소값 아래로 내려가지 않습니다. 보안실은 이 기본 시간의 ×2를 사용하며 원형 게이지도 해당 방의 실제 소요 시간으로 계산합니다.

별도 ID 25 **즉시 소등**은 첫 진입 때 방마다 한 번 추첨합니다. Lv.1–5 기본 확률은 5/10/15/20/25%이며 소등 속도 강화 Lv.2를 요구합니다. 성공은 즉시 완료, 실패는 남은 시간 작업을 진행합니다. 방을 떠나거나 진행도가 만료되거나 재접속해도 같은 방을 다시 추첨하지 않습니다. 대시·상승은 실제 방에 머문 시간만 누적하며 지나간 모든 방을 보장 즉시 소등하지 않습니다.

최초 처리 방마다 콤보를 1 올리고 유지 시간 4초를 갱신합니다. 직접·연동·연쇄·자동 소등도 새 방이면 인정합니다.

| 콤보 | 해당 소등의 배율 |
| ---: | ---: |
| 1–4 | ×1 |
| 5–9 | ×1.2 |
| 10–19 | ×1.5 |
| 20 이상 | ×2 |

이전 수입을 소급하여 올리지 않습니다. 유지 시간 종료 시 현재 콤보는 0이 되며 이번 근무의 최고 콤보는 남습니다. 재점등한 고장 난 전등을 다시 끄면 조명만 처리하고 돈·XP·콤보를 중복 지급하지 않습니다.

## 5. 무작위 수익과 정확한 장부

수익 분류는 아래 7개이며 합계는 실제 이번 근무 총수입과 같습니다.

| 항목 | 계산 / 기본 설정 |
| --- | --- |
| 기본 소등 수익 | 최초 완료한 방의 기본 수익 `B` |
| 건물 등급 보정 | `B × (G - 1)`. 낮은 등급이면 음수 |
| 무작위 보너스 | 일반 방마다 `B × R`, `R=0/0.5/2/10`을 65/25/8/2% 추첨 |
| 숨겨진 돈다발 보너스 | 선택된 일반 방의 `B × 5–20`. 기본 1–3개/건물, 발견 횟수도 집계 |
| 특수 방 보너스 | 종류별 기본 수익에 대한 추가 보상 |
| 콤보 보너스 | `B × (현재 콤보 배율 - 1)` |
| 스킬·액세서리 보너스 | 이동 보너스 스킬의 추가 1회 수입 + 종료 전 황금 명찰 보너스 |

건물 등급은 절전 / 일반 / 야근 / 초호화를 20/50/25/5%로 추첨하며 `G=0.8/1/1.3/1.8`입니다. 등급은 기본 수익에 적용하고 무작위·돈다발·특수·콤보 내역을 다시 등급 배율로 곱하지 않습니다.

이동 보너스 ID 4는 해당 이동 소등의 **등급 반영 기본 + 무작위 + 돈다발 + 특수 + 콤보**를 스킬 항목으로 한 번 더 더하여 기존 ×2 효과를 유지합니다. 자동 원점에는 적용하지 않습니다. 황금 명찰은 종료 전에 최고 콤보 × 0.25/레벨을 한 번 더합니다.

건물 등급·특수 방·돈다발 배치는 시작 때 정하고 저장합니다. 일반 보너스는 최초 완료 시 추첨하여 결과를 저장합니다. 이미 지급한 방의 조명·보상·XP는 독립 상태로 관리하여 재점등 후에도 중복 지급하지 않습니다. 이전 저장의 분류 정보가 없으면 원래 총수입을 **이전 근무 총수익 (미분류)**에 보존하고 등급 기록 없음으로 표시합니다.

## 6. 월세·수입 선택·정산 UI

완료 또는 시간 만료 후 실제 건물을 배경으로 반투명 검은 오버레이와 **근무 종료!** 화면을 표시합니다.

- 중앙 상단: 직접 / 연쇄·자동 / 전체 소등, 7개 수익 내역·총수입, 최고 콤보·배율, XP 5개 분류, 특수 방 6종 처리 수
- 중앙 하단: 보유금, 월세·납부 후 잔액, 부족금·진행 바, 5회 기회
- 오른쪽: 영구 관리인 레벨·XP 바와 특수 방 해금 목록
- 하단 5개 버튼: 파랑 스킬 강화 / 보라 액세서리 / 황금 월세 납부 / 빨강 퇴근 룰렛 / 초록 다음 근무

추가 수익은 주황색, 기본 수치는 흰색, 음수·부족금은 빨간색, XP 바는 밝은 초록색입니다. 아이콘·텍스트·버튼·바는 각각 제어 가능한 uGUI이며 참고 이미지를 통째로 붙이지 않습니다. 화면이 좁으면 정산 구성 전체를 비율 유지하여 중앙에 맞추고 배경 오버레이는 전체 화면을 덮습니다.

이번 수입과 기존 보유금은 분리합니다. 미정산 장부는 **수입 ×1 확정 후 예상금 = 기존 보유금 + 이번 수입**이며 실제 은행 잔고가 아닙니다. 스킬 강화·월세 납부·다음 근무를 선택하면 먼저 ×1을 확정합니다. 액세서리는 읽기 전용으로 열고 정산 선택·장착을 바꾸지 않습니다. 같은 DAY의 다음 근무는 장착을 유지합니다.

마지막 기회에 다음 근무는 비활성화되지만 총수입 행의 작은 ×1 확정 버튼으로 수입을 결정할 수 있습니다. 월세가 충분하면 납부, 부족하면 게임오버입니다. 새 도전은 DAY·보유금·일반 스킬을 초기화하고 영구 XP·레벨·해금·관리인 포인트·액세서리를 유지합니다. 마지막 정산 후의 일반 강화는 월세 예비금이 부족해지면 거절합니다.

월세는 보유금에서 정확히 차감하고 잔액·일반 스킬을 다음 DAY로 이월합니다. 다음 DAY 로비는 새 5회 기회이며 남은 이전 기회는 소멸합니다.

## 7. 선택 퇴근 룰렛

| 결과 | 기본 실제 확률 | 저장 슬롯 |
| --- | ---: | --- |
| NOTHING · ×0 | 60% | 10–19 |
| ×2 | 37% | 0–9 |
| ×10 | 3% | 20 |

종류의 가중 확률을 추첨하고 ×0·×2 그룹 안에서는 각 10개 저장 슬롯에 균등 분배합니다. 시각적 칸의 면적·각도도 실제 확률을 반영하며 ×2·NOTHING을 섞습니다. ×10은 한 칸입니다. 21개 저장 ID를 유지하지만 동일 확률 21칸은 현재 규칙이 아닙니다.

기존 보유금은 걸지 않고 이번 근무 총수입에만 적용합니다. ×1 확정과 룰렛은 한 번만 선택할 수 있으며 이미 정산하면 룰렛 버튼은 비활성화됩니다. 별도 팝업을 열기만 하면 베팅하지 않아 준비 중 닫을 수 있습니다.

돌리기 후 결과·지급을 먼저 저장하고 티켓 이동 0.9초 + 가속 0.75초 + 고속 1.1초 + 감속 3초 + 공개 0.65초, 총 약 6.4초를 연출합니다. 창 열기 약 0.4초는 별도입니다. 조명·포인터·틱·펄스를 사용하며 결과별 감속을 조작하지 않습니다. 공개·복귀 전 메인 장부를 고정하고 회전 중 ESC·T·지급·구매·다음 근무·중복 추첨을 차단합니다.

## 8. 영구 XP·레벨·특수 방

관리인 레벨은 1에서 시작합니다. 레벨 `L`에서 다음 레벨로 필요한 XP는 `50 + 25 × (L - 1)`입니다. 누적 50 XP가 Lv.2, 125 XP가 Lv.3이며 기본 상한은 Lv.100입니다. XP와 레벨은 관리인 포인트와 별개의 영구 진행입니다.

| 최초 완료 이벤트 | 기본 XP |
| --- | ---: |
| 일반 방 직접 소등 | 1 |
| 일반 방 연쇄·자동 소등 | 1 |
| 특수 방 소등 | 3, 일반 방 XP와 중복하지 않음 |
| 해당 근무의 최초 층 완료 | 2 |
| 건물 전체 완료 | 10 |

방별 최초 지급, 층별 최초 지급, 건물 완료 지급 여부를 저장합니다. 동일 방·재점등·로드·중복 종료로 재지급하지 않습니다. 정상 DAY 1의 40개 방·2층 완전 소등은 기본 54 XP입니다. 게임오버 후에도 누적 XP·레벨은 남습니다.

| 영구 레벨 | 특수 방 | 기본 효과 |
| ---: | --- | --- |
| 3 | 황금 전등 | 기본 수익 ×4 추가 |
| 5 | 배전실 | 같은 층 주변 3–6개 방 소등 |
| 8 | 보안실 | 작업 시간 ×2, 기본 수익 ×3 추가 |
| 12 | 연결 전등 | 주변 2–3개 방을 0.08초 간격으로 처리 |
| 16 | 비상 발전기 | 남은 시간 +3초, 근무당 연장 최대 +30초 |
| 20 | 고장 난 전등 | 기본 수익 ×1 추가, 5초 후 한 번 재점등 |

특수 방은 미해금 상태에서 생성하지 않습니다. 시작 레벨과 DAY를 사용하고 그 배치를 저장합니다. 기본 생성 확률은 순서대로 2/1.5/1.5/1.2/1/2%이며 DAY마다 설정 증가분을 반영합니다. 전체 특수 비중이 과도해지면 정규화합니다. 도미노 자손이 다시 배전실·연결 전등을 재발동하지 않으며 일반 전파 한도도 함께 적용합니다.

경험치는 소등 때 실제 지급하고 정산의 XP 바는 그 결과를 부드럽게 재현합니다. 레벨마다 바가 찬 한 프레임을 보여준 뒤 숫자·바 기준을 갱신합니다. 새 해금은 열린 자물쇠·발광·알림으로 표시합니다. 건너뛰기·팝업·다른 메뉴·화면 재열기는 경험치를 새로 지급하지 않습니다.

## 9. 관리인 포인트·액세서리

최고 완납 DAY보다 높은 DAY를 처음 낼 때 `1 + min(3, 남은 기회)` 포인트를 받습니다. 남은 기회 3–4/2/1/0은 각각 4/3/2/1포인트입니다. 최고 기록 이하의 DAY를 반복하여 포인트를 늘리지 않습니다.

액세서리는 최대 3개, 새 DAY / 재시작 로비에서만 변경합니다. 장착 효과는 근무 시작 시 복사합니다. 정산에서는 기존 액세서리 UI를 읽기 전용으로 재사용합니다.

| 액세서리 | 기본 효과 / 강화 |
| --- | --- |
| 절전 장갑 | 미완료 진행도 보존 +0.5초/레벨 |
| 야근 운동화 | 콤보당 이동속도 +1%, 레벨마다 +0.5%p, 최대 20콤보 |
| 관리인 열쇠 | 시작 3개 자동 소등, 레벨마다 +2개, Lv.5 11개 |
| 누전 반지 | 직접 소등 후 주변 1개 처리 확률 +10%/레벨, Lv.5 범위 2칸 |
| 황금 명찰 | 최고 콤보 × 0.25/레벨을 종료 전에 한 번 가산 |

미장착 효과는 0, 기본 상한 Lv.5, 최초 가격 3/4/5/5/6포인트, 가격 성장률 1.8입니다. 열쇠·반지·명찰도 이미 처리한 방의 수익을 재지급하지 않습니다. 명찰 수입은 이번 총수입과 룰렛 대상에 포함합니다.

## 10. 설정·저장·렌더 한도

설정은 `Assets/LightsOut/Resources/LightsOutBalanceSettings.asset`에서 조절합니다. DAY 형상·시간·월세·작업·즉시 추첨·스킬 DAY·콤보·등급·무작위 보너스·돈다발·특수 방·XP 성장·전파 예산·룰렛·액세서리 비용을 데이터로 관리합니다. 현재 계획의 `columns/floors/roomWidth/duration/rentDue`는 캠페인에 저장합니다.

| 저장 | 버전 / 위치 |
| --- | --- |
| 게임 외부 저장 | v3, PlayerPrefs `LightsOut.Rent.v3`, `lightsout-rent-save.json` |
| 캠페인 | v2, DAY 계획·시작 기회·연장 시간·정산·룰렛·작업 JSON |
| 작업 모델 | v5, 26스킬·방별 지급·추첨·특수·수익·XP 내역·장비·전파 예산 |
| 영구 진행 | v2, 포인트·장착·누적 XP. PlayerPrefs 키는 호환 유지 `LightsOut.Permanent.v1` |
| 영구 파일 | `lightsout-permanent-save.json` |
| 작업 진행도 | Mover v2, 게임 외부 저장 `workProgress` |

파일은 `Application.persistentDataPath`에 쓰며 현재 로드는 PlayerPrefs를 사용합니다. 캠페인 재시작은 별도 영구 진행 인스턴스를 지우지 않습니다.

작업 v2/v3의 20/22스킬, v4의 24/25스킬은 26개로 승격합니다. 예전 캠페인 v1은 현재 DAY의 옛 건물·시간·월세를 유지하고 Working의 종료 횟수만 시작 횟수로 +1 변환합니다. 다음 DAY부터 새 계획을 적용합니다. 예전 영구 v1은 포인트·장착·최고 완납을 유지하고 새 XP를 0 / 레벨 1로 시작합니다. 작업 진행도 v1은 해당 방의 완료 비율을 새 소요 시간으로 옮깁니다.

표시는 48개 층 × 20개 방 슬롯을 재사용하고 화면 밖 열을 숨깁니다. 논리 4,096층을 동시에 렌더링하지 않습니다. 소득 팝업 24개, 스파크 48개, 상승 SpriteRenderer 12개, 작업 원형 게이지 32개 구간 등 고정 풀을 사용합니다. 신규 정산 아이콘은 자체 픽셀 도형이며 기존 씬·프리팹·스킬·액세서리·룰렛을 재사용합니다.

### 이전 월세 MVP에서 실제 회전 중 저장 복원

별도의 검증용 상태에서 슬롯 20의 ×10 결과가 나온 직후, 회전이 끝나기 전에 실제 저장 파일과 PlayerPrefs에 **정산 완료·보유금 50·슬롯 20·배수 10**이 기록된 것을 확인했습니다.

이 상태로 Unity **Stop → Play**를 수행한 후 아래를 확인했습니다.

- 정산 후 상태 `BetweenAttempts`, 사용 기회 1회, 보유금 50 복원
- 슬롯 20, 배수 10 유지
- 회전 상태 `IsSpinning=false`, 휠 각도 약 342.857°로 즉시 정렬
- 게임 일시 정지 `IsPaused=true`: 종료된 근무에 복귀하지 않음
- 재추첨 요청 거절

마지막 컴파일은 오류 0개로 성공했습니다. 이 검증은 전체 게임의 장기 밸런스나 고층 전체 수동 플레이 완료를 증명하지 않습니다.

최종 실행 콘솔 오류와 누락된 스크립트는 0개입니다. Unity AI 패키지의 Account API 연결 시간 초과 경고 1개는 게임 로직과 별도로 남아 있습니다. 검증용 저장 데이터는 작업 전 상태로 복원했으며 테스트 수입·강화를 남기지 않았습니다.
