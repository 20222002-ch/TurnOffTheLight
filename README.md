# TurnOffTheLight

Unity 2D 게임 **불 끄고 퇴근해! — Lights Out!**의 프로젝트입니다. 넓고 낮은 야간 마트에서 좁고 높은 빌딩으로 이동하며 불을 끄고, DAY마다 최대 5번의 근무로 월세를 갚습니다.

현재는 26개 일반 스킬, 실제 근무 결과 정산, 선택 퇴근 룰렛, 무작위 수익·돈다발, 6종 특수 방과 영구 관리인 레벨·액세서리를 구현하는 MVP입니다. 일반 스킬·보유금은 게임오버 시 초기화되며 영구 XP·특수 방 해금·액세서리는 남습니다.

- Unity **6000.3.8f1**, URP 2D, uGUI, Input System
- 실행 씬: `Assets/LightsOut/Scenes/LightsOut.unity`
- [실행·조작·시스템 안내](Documentation/README.md)
- [DAY·수익·월세·영구 성장 규칙](Documentation/RENT-RULES.md)
- [버전별 실제 검증 기록](Documentation/PLAYTEST.md)

정산 UI와 신규 경제·XP 기능의 최종 검증 상태는 PLAYTEST 기록을 따릅니다. 실행 파일 빌드와 Notion 작업은 이번 작업 범위에 포함하지 않습니다.
